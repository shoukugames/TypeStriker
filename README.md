# Type Striker

A typing vertical shooter for all ages, by [Shouku Games](https://shoukugames.org/).

Your spaceship rides on rails, so you never have to steer. All you do is **type**.
Press the letter or spell the word behind each enemy to shoot it down before it reaches you.

- 10 distinct levels: 5 in space, 4 on planets with tanks, and one on the hull of the enemy flagship
- 10 bosses, each with its own design and attack pattern
- 6 kinds of enemy spaceship, plus tanks, asteroids and missiles, each with its own explosion sound
- Top 10 score table, and speed and accuracy saved for every level
- A hand-picked, child-friendly word list that doesn't repeat during a game
- Home screen, instructions, credits and all other menus in **English and Japanese**
  (the typing itself and the in-game display are in English)
- Ship, enemy and sound artwork generated by the game's code, with no image or audio files to load

## Install

Download a release, or [build it yourself](#build-the-installers).

**Linux (Debian, Ubuntu and similar, 64-bit):**

```bash
sudo apt install ./typestriker_v0.1.1_amd64.deb
```

Start it from your applications menu or by running `typestriker`.
To remove it: `sudo apt remove typestriker`.

**Windows (64-bit):** double-click `TypeStriker-v0.1.1.exe`. Nothing needs installing.
The first start takes a few seconds while it unpacks. Windows SmartScreen may warn about
an unsigned download; choose **More info**, then **Run anyway**.

**From source (Python 3.10 or newer):**

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python run_game.py
```

## How to play

| Key | Action |
|---|---|
| Letters A-Z | Fire at the matching enemy, or dodge the matching shot (capitals and lowercase both work) |
| Backspace | Drop your current target and pick another, or restart a dodge you began |
| Esc | Pause |
| F11 | Full screen on or off |
| F2 | Mute or unmute |
| F3 | Switch the menus between English and 日本語 (also in the top right corner and under Options) |

- **Scoring:** each correct letter scores **100**. Destroying a boss adds a **1,000** bonus.
- **Enemies:** an enemy takes one hit per letter, so a single letter on levels 1-3 takes one hit,
  and an 8-letter word on level 10 takes eight.
- **Target lock:** once you start a word your ship stays locked on it until it is finished.
- **Bosses:** every boss takes exactly **10 shots**. Each shot is fired by finishing one letter
  (levels 1-3) or one whole word (levels 4-10), and the letters along the way score as usual.
- **Dodging:** enemies and bosses fire back, and a shot always lands unless you dodge it. Each shot
  carries a red tag, also shown at the bottom of the screen with a timer bar. Type the tag and your
  ship rolls out of the way. Tags are one letter on levels 1-3, two on levels 4-6 and three on
  levels 7-10, and each letter scores 100. A dodge pauses the word you are typing, which carries on
  afterwards from where you stopped. Asteroids and missiles don't shoot: stop those by shooting them.
- **Damage:** you have **3 lives**, each with a **10-hit** hull bar. Each enemy attack that lands
  or crash costs one hit. Clearing a level repairs 3 hull points.
- **Speed** is shown in words per minute, counting 5 letters as a word. Only time with something
  on screen to type at is counted, so waiting for enemies doesn't lower it.
- **Accuracy** is correct keys out of all keys pressed while there was something to shoot at.

## Where your data is saved

| System | Folder |
|---|---|
| Linux | `~/.local/share/typestriker/` |
| Windows | `%APPDATA%\TypeStriker\` |

The folder holds `scores.json` (Top 10), `progress.json` (speed and accuracy per level, with the
last 20 attempts) and `settings.json`. Delete a file to reset it.

For practice, `typestriker --level 7` starts directly on a level.

## Build the installers

On Debian or Ubuntu, with `python3-venv`, `dpkg-dev`, `wine`, `wine64` and `xvfb` installed:

```bash
./build.sh                     # both
packaging/build_linux.sh       # dist/typestriker_v<version>_amd64.deb
packaging/build_windows.sh     # dist/TypeStriker-v<version>.exe
```

The Windows build runs Windows Python under Wine, and its first run downloads Python from
python.org. Each script finishes by starting the packaged game and playing a few seconds of it.

`build/` and `dist/` are in `.gitignore`, so no binaries are committed.

The version comes from `typestriker/__init__.py` and appears in both file names. Raise it and add a
line to the [changelog](#changelog) for every new build.

## Development

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests        # includes a full 10-level playthrough by a robot
.venv/bin/python tools/balance.py       # how far typists of different speeds get
.venv/bin/python tools/screenshots.py /tmp/shots    # picture of every level and screen
.venv/bin/python tools/make_icon.py     # redraws assets/icon.png and icon.ico
```

| File | Contains |
|---|---|
| `typestriker/config.py` | All ten level definitions and the game rules: **start here to tune difficulty** |
| `typestriker/words.py` | The word list and the no-repeat dealing |
| `typestriker/i18n.py` | All English and Japanese menu text |
| `typestriker/play.py` | Typing rules, damage and the level flow |
| `typestriker/entities.py` | Player, enemies, bosses, shots |
| `typestriker/art.py` | Ship, enemy and boss artwork |
| `typestriker/backgrounds.py` | The ten level backdrops |
| `typestriker/audio.py` | Sound effects and the music sequencer |
| `typestriker/scenes.py`, `hud.py`, `ui.py` | Menus, result screens and the in-game display |
| `typestriker/storage.py` | Top 10, progression and settings files |
